# Quranic Syllable Counting Rules

## Rule 1: The Obligatory Onset
Every syllable must begin with a consonant. No syllable opens with a bare vowel. What appears to be a vowel-initial word always has a hamza (ء) as its onset consonant, even when orthographically invisible (like Hamzatul Wasl ٱ).

## Rule 2: Syllable Types
- **CV**: Consonant + Short Vowel (e.g., بَ)
- **CVC**: Consonant + Short Vowel + Sukun (e.g., مِنْ)
- **CVV**: Consonant + Long Vowel (e.g., قَا)
- **CVVC**: Consonant + Long Vowel + Sukun (e.g., بَابْ)
- **CVCC**: Consonant + Short Vowel + Two unvoweled consonants (Pausal only).

## Rule 3: The Waqf Rule (Crucial)
In waqf (stopping), the final short vowel of a verse is dropped. 
- If the last letter carries a short vowel (Fatha, Kasra, Damma), it loses that vowel and closes the preceding syllable.
- This reduction decreases the total syllable count by exactly one.

## Rule 4: The Shadda
A letter with a Shadda (geminate) closes the syllable before it and opens the syllable after it. It marks a boundary: (CVC | CV).

## Implicit Omissions in Uthmani Script
- **Allah (ٱللَّهُ)**: Contains an implicit long 'ā' (Khanjariya) on the second Lam, even if not written.
- **Initial Hamzatul Wasl (ٱ)**: At the beginning of a phrase, it provides an implicit Fatha onset (/a/).
